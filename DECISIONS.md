# NONZERO Product & Architecture Decisions

## 2026-08-30 — Stable pairing is sacred
Six-digit phone → Roku pairing and Wall-token state access are release invariants.

## 2026-08-30 — Basecamp
Phone v3.5 + Worker v4.1 + Roku v4.3.3 is the immutable hardware-verified rollback point.

## 2026-08-30 — ErgData-first
ErgData owns PM5 Bluetooth. NONZERO does not create a competing recorder.

## 2026-08-31 — Wall overnight model
NONZERO should remain foregrounded in Deep Panel Protect so its own scheduling heartbeat can return to Ambient. Roku/TV system power settings remain an external constraint.

## 2026-08-31 — Completed-day psychology
Workout completion should change Wall presentation and quote weighting toward accomplishment plus future consistency.

## 2026-08-31 — Surgery date becomes a first-class state
Once known, surgery date drives a live pre-op countdown and motivational/program phase. It does not override pain/readiness or clinical guidance.

## 2026-08-31 — Simple BikeErg trigger
The automatic trigger is ErgData `Is Opened`. Worker v4.3 uses an opaque one-link URL so the Shortcut needs no POST/header/private key configuration.

## 2026-08-31 — Mobile information hierarchy
Phone Today prioritizes training decisions/actions. Wall administration belongs in Settings.
