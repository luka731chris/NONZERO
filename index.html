Calendar help
iPhone/iCloud: paste the exact link produced by Calendar → Calendars → ⓘ → Public Calendar → Share Link. The planner accepts webcal://, webcals://, http://, and https://, extracts links even when surrounded by copied text, and retries Apple-specific host variants automatically. If Apple blocks browser access, the planner shows an Apple-specific download/import fallback instead of treating the link as invalid.

GameChanger / TeamSnap: copy each team's calendar subscription link and add it directly above. Keeping each team separate allows refreshes to replace that team's events cleanly when practices move or games are cancelled.

Recurring events: AutoPilot supports daily, weekly, monthly, and yearly recurrence patterns plus cancellations, excluded dates, and moved single instances.

Calendar Gateway (recommended for reliable team-calendar sync): GitHub Pages cannot override CORS restrictions imposed by Apple or other calendar hosts. If you deploy the tiny companion proxy included with v32, paste its HTTPS URL here once. The planner will use it only after a direct calendar fetch fails.
