Set up signed Wall pairing

Worker 5.15 replaces the old unsigned Wall credential. Create a server-only signing key before deploying, then pair the Wall once.

  1. In Cloudflare, open Workers & Pages → nonzero_sync → Settings → Variables and Secrets → Add.
  2. Select Secret. Name it exactly NONZERO_SIGNING_KEY.
  3. Generate a value below and paste it into the Cloudflare secret. Save it in your password manager if you need to restore this Worker later.
  4. Keep your existing NONZERO_STATE KV and NONZERO_COACH D1 bindings. Deploy worker.js.
  5. Open the Worker’s /health URL. Confirm version 5.15, signingKeyConfigured: true, and pairingModel: "signed-v3".
  6. In the phone app’s Settings, create a new Wall pairing code and enter it in the Pi’s pairing screen. Your existing workout and coaching records stay in their existing account.

This page generates the key in your browser. It sends no network requests, stores no key, and includes no tracking. Keep the value out of GitHub and release files. Rotating it later invalidates existing signed Wall tokens and requires re-pairing.
