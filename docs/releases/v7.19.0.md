# NONZERO v7.19.0 — Conversational Nutrition (release candidate)

## Deploy
1. Back up current Phone `index.html`, Nutrition Worker, and D1 data.
2. Run `Database/schema-conversational.sql` in the EXISTING Nutrition D1 database Console. This is additive.
3. Deploy `Worker/index.js` to the EXISTING Nutrition Worker. Keep existing `DB`, `API_TOKEN`, `ALLOWED_ORIGINS`, `USDA_API_KEY`, and `OPENAI_API_KEY` bindings/secrets.
4. Optionally configure `OPENAI_NUTRITION_MODEL` (default `gpt-4.1-mini`). The cost estimator uses default input/output rates of $0.40/$1.60 per million tokens for this model; verify current rates before relying on these estimates. Override via `AI_INPUT_USD_PER_M_TOKEN`, `AI_OUTPUT_USD_PER_M_TOKEN` Worker variables.
5. Verify `/version` returns `7.19.0`; authenticated GET `/v3/nutrition/usage` should return the current month and budget.
6. Replace GitHub Pages Phone `index.html` with `Phone/index.html`. Hard-refresh and verify version.
7. Test natural-language analysis of one meal, review/edit items, save, then confirm D1 and laptop synchronization. Test duplicate prevention and delete propagation before broad use.

## Features
- Text description -> AI structured item estimates -> editable item-by-item review -> bulk log through the existing Phone nutrition form and its automatic D1 sync.
- Local deterministic Today and last-seven-day summaries, calorie/protein target gap and lightweight guidance. Average is explicitly limited to logged days.
- Monthly D1 AI usage ledger with a $5 application-level threshold, $3 warning metadata, and $0.03/request reservation for concurrency protection. Failed requests release reservation.
- USDA/Open Food Facts smart search, photo analysis, barcode lookup, nutrition cloud settings, and existing workout/AutoPilot interface are retained from v7.18.3.0.

## Accuracy and limitations
- AI estimates are **not** verified label values. The model interprets meal descriptions and estimates nutrition, but this release does not perform per-item live USDA grounding for conversational entries. Review numbers before saving.
- Saved favorite foods are supplied as optional reference data; not all recipe ingredients or prior chat history are accessible to the Worker.
- The cost ledger estimates OpenAI costs from reported tokens and configured rates. It is **not** an OpenAI billing limit; photo analysis uses a separate endpoint and is **not** counted toward this $5 conversational budget. Other apps using the same OpenAI project can also incur charges. Set OpenAI project budget alerts separately. For a hard overall application cap, all AI endpoints must share a central limiter and reserve against worst-case cost.
- The phone must be active for background syncing. This release does not modify the Pi, AutoPilot backend, or D1 records schema.
- No live end-to-end Cloudflare/iPhone test was possible here; deploy as a candidate, not a verified production release.

## Rollback
Restore previous Phone HTML and Worker JS. The new D1 table can remain unused; no destructive migration is needed.
